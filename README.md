## Featured Projects

### [Krave](https://github.com/deep4nsh/krave) — Campus Canteen Pre-ordering Platform

A full-stack, multi-app Flutter ecosystem for campus dining — connecting students, canteen owners, and delivery riders. Built as a mono-repo with three distinct Flutter applications and a serverless Firebase backend.

- **Student app** with live order tracking, Razorpay payments, and PDF invoice generation
- **Rider app** with 6-stage KYC onboarding and delivery management
- **Admin portal** for canteen approvals and platform governance
- **Cloud Functions** handling payment verification, FCM push notifications, and order lifecycle events

`Flutter` `Dart` `Firebase` `Razorpay` `Node.js` `Cloud Functions`

---

### [dtuhostel.in](dtuhostel.in) — DTU Hostel Allotment System

A production-grade, full-stack web platform automating hostel seat allocation for Delhi Technological University. Deployed on AWS and actively used by the university.

- **Student portal** with OCR-assisted document upload, preference selection, and digital allotment letters
- **Admin dashboard** with bulk CSV import, a gender/category-based allocation engine, and system health monitoring
- **Monorepo architecture** — Next.js frontend, NestJS backend, PostgreSQL + Redis, deployed on AWS EC2/RDS

`Next.js` `NestJS` `TypeScript` `PostgreSQL` `Redis` `Prisma` `AWS`

---

### [SliceIt](https://github.com/deep4nsh/sliceit) — Smart Expense Splitting App

A premium Flutter expense-splitting application with offline-first architecture, greedy debt simplification, and deep analytics.

- **Greedy algorithm** to minimise transactions within groups
- **Offline mode** via Hive caching with automatic sync queue on reconnection
- **Receipt OCR** using Google ML Kit for itemised bill splits
- **Rich analytics** with pie, bar, and line charts via fl_chart; PDF export support

`Flutter` `Dart` `Firebase` `Hive` `Google ML Kit` `Node.js`

---

### [dots](https://github.com/deep4nsh/dots) — AI-Powered Thought Capture

A minimalist Flutter app for capturing thoughts and surfacing patterns through AI-driven insights.

- **Gemini AI** integration for daily summaries, weekly reflections, and thematic analysis
- **Multi-format capture** — text, images, and voice notes
- **Visual analytics** tracking mental trends over time
- **Real-time sync** across devices via Supabase

`Flutter` `Dart` `Supabase` `Google Gemini` `Riverpod`
